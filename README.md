## 🛠️ The Philosophy

- **Zero Utility**: Solves zero real-world problems.
- **Iron Functionality**: All modules must genuinely work. Modulo checks must yield truth; coins must flip; dates must be accurate.
- **Console Corruption**: Browser console is flooded with colorful, dramatic ASCII kernel panics.
- **Painful UX & Hostile Layout**: Asymmetrical paddings, mismatched margins, unaligned windows, and hostile interaction models.
- **Strict Anti-Linting**: Clean code is rejected at the CI gate.

## 🚨 Contributor Guidelines (READ BEFORE SUBMITTING A PR)

### Rule 1: The Anti-Improvement Law (Instant Auto-Reject)
> **ANY PULL REQUEST THAT MAKES THE CODE CLEANER, FASTER, MORE INTUITIVE, OR BETTER WILL BE STRAIGHT-AWAY REJECTED.**

### Rule 2: Zero Semicolons Allowed
- Semicolons (`;`) are strictly forbidden across the codebase.
- Verified automatically via `npm run lint:cursed`.

### Rule 3: Commit Message Protocol
Conventional Commits (`feat:`, `fix:`, `chore:`, etc.) are **banned**.
Commit messages must reflect exhaustion, confusion, or chaotic energy.
- ✅ Accepted: `made the button louder`, `fixed nothing`, `aaaaaaaaaaaa`, `why does this work`
- ❌ Rejected: `feat: add module`, `fix: update padding`, `chore: clean up`
- Verified automatically via `npm run lint:commit`.

### Rule 4: Test Protection Policy
- **Existing core tests CANNOT be modified or deleted.**
- You cannot nerf existing test assertions to make tests pass.
- **Writing NEW tests for new modules is warmly welcomed and required!**
- Verified automatically via `npm run test:integrity`.

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/your-username/useless-os.git

# Enter project
cd useless-os

# Install dependencies
npm install

# Run the local dev server
npm run dev

# Run automated checks
npm run lint:cursed     # Fails if clean code or semicolons found
npm run lint:commit     # Fails if professional commit messages found
npm run test:integrity  # Fails if existing test suites were nerfed
npm test                # Vitest test suite (must pass 100%)
```
